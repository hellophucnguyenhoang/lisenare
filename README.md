# Lisenare API

**Lisenare (Listen and Repeat)** is a backend service for an English learning app focused on speaking fluency through short, practical sentences called *bricks*.

## Concept

Users learn English by listening and repeating small real-world sentences they actually want to use in daily life.

Instead of fixed lessons, learners:
- Add sentences they personally want to speak
- Practice them through an automated repetition scheduler
- Keep track of their learning progress

The system automatically determines when each sentence should be reviewed to help long-term retention.

## Core Idea

> Learn English by repeatedly practicing the exact sentences you need in real life.

## Current Focus

- Sentence (brick) management per user
- Personalized practice system
- Self-driven vocabulary and sentence collection
